# Proiecte exemplu

Fiecare proiect se deschide în editorul ctrl32 (**File → Open**) și rulează pe LaskaKit ESPlan așa cum este.

| | Proiect | Ce arată |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.ro.md) | O ieșire de motor cu start / stop, un temporizator de funcționare, un nivel analogic, o temperatură Modbus RTU, cadre CAN, un contor Modbus TCP, MQTT și pagina operatorului într-un browser. |
