# Приклади проєктів

Кожен проєкт відкривається в редакторі ctrl32 (**File → Open**) і працює на LaskaKit ESPlan як є.

| | Проєкт | Що він показує |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.uk.md) | Вихід двигуна з пуском / зупинкою, таймер роботи, аналоговий рівень, температура Modbus RTU, кадри CAN, лічильник Modbus TCP, MQTT і сторінка оператора в браузері. |
