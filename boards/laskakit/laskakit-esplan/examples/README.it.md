# Progetti di esempio

Ogni progetto si apre nell'editor ctrl32 (**File → Open**) e funziona così com'è sulla LaskaKit ESPlan.

| | Progetto | Cosa mostra |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.it.md) | Un'uscita motore con start / stop, un timer di funzionamento, un livello analogico, una temperatura Modbus RTU, frame CAN, un contatore Modbus TCP, MQTT e la pagina operatore in un browser. |
