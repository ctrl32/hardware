# Beispielprojekte

Jedes Projekt öffnet sich im ctrl32-Editor (**File → Open**) und läuft so, wie es ist, auf dem Olimex ESP32-S3-DevKit-Lipo.

| | Projekt | Was es zeigt |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.de.md) | Ein Motorausgang mit Start / Stop, einer Laufzeit, einem analogen Füllstand, einer Modbus-RTU-Temperatur, CAN-Frames, einem Modbus-TCP-Zähler, MQTT und der Bedienseite in einem Browser. |
