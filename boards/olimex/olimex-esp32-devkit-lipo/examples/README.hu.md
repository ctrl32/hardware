# Példaprojektek

Minden projekt megnyílik a ctrl32 szerkesztőben (**File → Open**), és változtatás nélkül fut a(z) Olimex ESP32-DevKit-LiPo panelen.

| | Projekt | Mit mutat |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.hu.md) | Egy motorkimenet start / stop vezérléssel, futásidővel, analóg szinttel, Modbus RTU hőmérséklettel, CAN keretekkel, Modbus TCP mérővel, MQTT-vel és kezelőoldallal a böngészőben. |
