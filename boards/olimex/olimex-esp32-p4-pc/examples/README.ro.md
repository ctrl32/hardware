# Proiecte exemplu

Fiecare proiect se deschide în editorul ctrl32 (**File → Open**) și rulează pe Olimex ESP32-P4-PC așa cum este.

| | Proiect | Ce arată |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.ro.md) | O ieșire de motor cu start / stop, un temporizator de funcționare, o temperatură Modbus RTU, cadre CAN, un contor Modbus TCP, MQTT și pagina operatorului într-un browser. |
