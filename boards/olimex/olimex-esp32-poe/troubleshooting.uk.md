# Усунення несправностей

| Симптом | Причина | Рішення |
|---|---|---|
| COM-порт не з'являється, вибір порту залишається порожнім | Кабель передає лише живлення або бракує драйвера CH340 | Використайте кабель для даних; встановіть драйвер CH340 (WCH CH341SER); спробуйте інший USB-порт. |
| Flash runtime зупиняється під час підключення | Порт зайнято іншою програмою | Закрийте монітор послідовного порту або інший інструмент, який тримає порт відкритим, і спробуйте знову. |
| Плата перезапускається кожні кілька секунд | USB-порт не дає достатнього струму, коли запускається Ethernet | Використайте USB-хаб із власним живленням або блок живлення 5 В щонайменше на 1 А, або живіть плату від PoE (без USB). |
| Мережа не піднімається | Немає DHCP-сервера або немає з'єднання на порту | Перевірте світлодіоди з'єднання на гнізді; задайте фіксовану адресу на сторінці Ethernet; спробуйте інший порт комутатора. |
| Плату не знайдено за її іменем .local | Мережа блокує mDNS (multicast) | Використайте IP-адресу плати - її показують список клієнтів маршрутизатора та Find devices у редакторі. |
| USB від'єднується або ПК повідомляє про помилку, коли підключено кабель PoE | USB і PoE підключено одночасно до плати без гальванічної розв'язки | Негайно від'єднайте одне з них. Спершу завантажте через USB, потім працюйте від PoE - або використайте ESP32-PoE-ISO. |
| Вихід на GPIO34 - GPIO39 нічого не робить | Ці піни - лише входи | Перенесіть вихід на GPIO33, GPIO4 або GPIO5. |
| Значення Modbus залишається 0 | Неправильна адреса пристрою, unit чи регістр, або пристрій в іншій підмережі | Перевірте IP і unit пристрою в дереві пристроїв, а регістр - у посібнику пристрою; виконайте ping пристрою з ПК. |

Панель **Messages** редактора та **діагностичний буфер** плати (Online → Diagnostics) кажуть, що вирішив runtime і чому - прочитайте їх насамперед.
