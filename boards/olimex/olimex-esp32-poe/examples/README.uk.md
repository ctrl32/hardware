# Приклади проєктів

Кожен проєкт відкривається в редакторі ctrl32 (**File → Open**) і працює на Olimex ESP32-PoE як є.

| | Проєкт | Що він показує |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.uk.md) | Насос, яким керують кнопкою плати, зі сторінки оператора та з Home Assistant, з входом рівня, таймером роботи, аварійним сигналом рівня та лічильником енергії Modbus TCP. |
