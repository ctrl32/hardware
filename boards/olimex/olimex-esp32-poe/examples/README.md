# Example projects

Each project opens in the ctrl32 editor (**File → Open**) and runs on the Olimex ESP32-PoE as it is.

| | Project | What it shows |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.md) | A pump controlled by the board button, the operator page and Home Assistant, with a level input, a run timer, a level alarm and a Modbus TCP energy meter. |
