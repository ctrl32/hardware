# Beispielprojekte

Jedes Projekt öffnet sich im ctrl32-Editor (**File → Open**) und läuft so, wie es ist, auf dem Olimex ESP32-PoE.

| | Projekt | Was es zeigt |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.de.md) | Eine Pumpe, gesteuert über den Taster des Boards, die Bedienseite und Home Assistant, mit Füllstandseingang, Laufzeit-Timer, Füllstandsalarm und einem Modbus-TCP-Energiezähler. |
