# Proiecte exemplu

Fiecare proiect se deschide în editorul ctrl32 (**File → Open**) și rulează pe Olimex ESP32-PoE așa cum este.

| | Proiect | Ce arată |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.ro.md) | O pompă comandată de butonul plăcii, de pagina operatorului și din Home Assistant, cu o intrare de nivel, un temporizator de funcționare, o alarmă de nivel și un contor de energie Modbus TCP. |
