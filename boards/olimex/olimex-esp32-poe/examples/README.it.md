# Progetti di esempio

Ogni progetto si apre nell'editor ctrl32 (**File → Open**) e funziona così com'è sulla Olimex ESP32-PoE.

| | Progetto | Cosa mostra |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.it.md) | Una pompa comandata dal pulsante della scheda, dalla pagina operatore e da Home Assistant, con un ingresso di livello, un timer di funzionamento, un allarme di livello e un contatore di energia Modbus TCP. |
