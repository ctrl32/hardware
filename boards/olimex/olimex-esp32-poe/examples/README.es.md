# Proyectos de ejemplo

Cada proyecto se abre en el editor ctrl32 (**File → Open**) y funciona tal cual en la Olimex ESP32-PoE.

| | Proyecto | Qué muestra |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.es.md) | Una bomba controlada desde el botón de la placa, la página del operador y Home Assistant, con una entrada de nivel, un temporizador de marcha, una alarma de nivel y un contador de energía Modbus TCP. |
