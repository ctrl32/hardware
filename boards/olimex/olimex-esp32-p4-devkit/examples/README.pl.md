# Przykładowe projekty

Każdy projekt otwiera się w edytorze ctrl32 (**File → Open**) i działa na Olimex ESP32-P4-DevKit bez zmian.

| | Projekt | Co pokazuje |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.pl.md) | Wyjście silnika ze start / stop, czasem pracy, temperaturą Modbus RTU, ramkami CAN, licznikiem Modbus TCP, MQTT i stroną operatora w przeglądarce. |
