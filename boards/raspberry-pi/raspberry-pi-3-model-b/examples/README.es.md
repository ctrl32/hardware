# Proyectos de ejemplo

Cada proyecto se abre en el editor ctrl32 (**File → Open**) y funciona tal cual en la Raspberry Pi 3 Model B+.

| | Proyecto | Qué muestra |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.es.md) | Un motor y un ventilador en un módulo de E/S Modbus RTU, controlados desde la pantalla HDMI, WEBview y Home Assistant, con un contador Modbus TCP, tramas CAN, horas de funcionamiento, una tendencia, las alarmas y cada variable en OPC UA. |
