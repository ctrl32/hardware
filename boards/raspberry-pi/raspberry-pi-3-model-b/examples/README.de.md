# Beispielprojekte

Jedes Projekt öffnet sich im ctrl32-Editor (**File → Open**) und läuft so, wie es ist, auf dem Raspberry Pi 3 Model B+.

| | Projekt | Was es zeigt |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.de.md) | Ein Motor und ein Lüfter an einem Modbus-RTU-I/O-Modul, gesteuert vom HDMI-Bildschirm, aus WEBview und aus Home Assistant, mit einem Modbus-TCP-Zähler, CAN-Telegrammen, Betriebsstunden, einem Trend, den Alarmen und jeder Variablen auf OPC UA. |
