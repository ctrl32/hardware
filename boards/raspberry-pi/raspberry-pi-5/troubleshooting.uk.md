# Усунення несправностей

| Симптом | Причина | Рішення |
|---|---|---|
| Look at the device не може підключитися | SSH вимкнено, адреса неправильна або ПК в іншій мережі | Увімкніть SSH у налаштуваннях Imager і запишіть карту знову; виконайте ping адреси з ПК. |
| Prepare не пропонує встановлення | Runtime ctrl32 уже встановлено на Pi | Встановлений runtime оновлюється через Flash runtime з адресою Pi у виборі порту. |
| Монітор залишається чорним після завантаження проєкту | Монітор підключено після завантаження системи, або проєкт не має екрана | Підключіть монітор до увімкнення Pi; додайте екран до проєкту. |
| WEBview не відкривається | Неправильний порт | Відкрийте http://<адреса>:8080 - runtime працює на порту 8080. |
| Адаптер USB-RS485 зникає | Знижена напруга - блок живлення заслабкий | Використовуйте офіційний блок живлення 27 Вт. |
| CAN мовчить | Драйвер HAT не завантажено, немає термінування або інша швидкість передачі | Позначте HAT у Prepare a Linux device; резистор 120 Ом на обох кінцях шини; однакова швидкість на кожному вузлі. |
| Клієнт OPC UA не бачить змінних | Змінну виключено із сервера, або брандмауер блокує порт 4840 | Перевірте позначку OPC UA у списку змінних; відкрийте порт 4840. |

Панель **Messages** редактора та **діагностичний буфер** плати (Online → Diagnostics) кажуть, що вирішив runtime і чому - прочитайте їх насамперед.
