# Przykładowe projekty

Każdy projekt otwiera się w edytorze ctrl32 (**File → Open**) i działa na Raspberry Pi 5 bez zmian.

| | Projekt | Co pokazuje |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.pl.md) | Silnik i wentylator na module I/O Modbus RTU, sterowane z ekranu HDMI, WEBview i Home Assistant, z licznikiem Modbus TCP, ramkami CAN, licznikiem godzin pracy, wykresem, alarmami i każdą zmienną w OPC UA. |
