# Proiecte exemplu

Fiecare proiect se deschide în editorul ctrl32 (**File → Open**) și rulează pe Raspberry Pi 5 așa cum este.

| | Proiect | Ce arată |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.ro.md) | Un motor și un ventilator pe un modul I/O Modbus RTU, comandate de pe ecranul HDMI, din WEBview și din Home Assistant, cu un contor Modbus TCP, cadre CAN, ore de funcționare, un trend, alarmele și fiecare variabilă pe OPC UA. |
