# Projets d'exemple

Chaque projet s'ouvre dans l'éditeur ctrl32 (**File → Open**) et fonctionne tel quel sur la Raspberry Pi 5.

| | Projet | Ce qu'il montre |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.fr.md) | Un moteur et un ventilateur sur un module d'E/S Modbus RTU, commandés depuis l'écran HDMI, WEBview et Home Assistant, avec un compteur Modbus TCP, des trames CAN, les heures de marche, une courbe, les alarmes et chaque variable sur OPC UA. |
