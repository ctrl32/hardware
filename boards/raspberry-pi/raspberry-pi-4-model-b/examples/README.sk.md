# Vzorové projekty

Každý projekt sa otvorí v editore ctrl32 (**File → Open**) a beží na doske Raspberry Pi 4 Model B tak, ako je.

|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.sk.md) | Motor a ventilátor na I/O module Modbus RTU, ovládané z obrazovky HDMI, z WEBview a z Home Assistant, s elektromerom Modbus TCP, rámcami CAN, motohodinami, priebehom, alarmami a každou premennou na OPC UA. |
