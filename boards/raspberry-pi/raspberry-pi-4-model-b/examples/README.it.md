# Progetti di esempio

Ogni progetto si apre nell'editor ctrl32 (**File → Open**) e funziona così com'è sulla Raspberry Pi 4 Model B.

| | Progetto | Cosa mostra |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.it.md) | Un motore e un ventilatore su un modulo I/O Modbus RTU, comandati dallo schermo HDMI, da WEBview e da Home Assistant, con un contatore Modbus TCP, frame CAN, ore di funzionamento, un trend, gli allarmi e ogni variabile su OPC UA. |
