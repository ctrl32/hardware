# Приклади проєктів

Кожен проєкт відкривається в редакторі ctrl32 (**File → Open**) і працює на Raspberry Pi 4 Model B як є.

| | Проєкт | Що він показує |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.uk.md) | Двигун і вентилятор на модулі вводу/виводу Modbus RTU, якими керують з HDMI-екрана, WEBview і Home Assistant, з лічильником Modbus TCP, кадрами CAN, мотогодинами, трендом, аварійними сигналами та кожною змінною в OPC UA. |
