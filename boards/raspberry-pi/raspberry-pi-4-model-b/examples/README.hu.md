# Példaprojektek

Minden projekt megnyílik a ctrl32 szerkesztőben (**File → Open**), és változtatás nélkül fut a(z) Raspberry Pi 4 Model B panelen.

| | Projekt | Mit mutat |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.hu.md) | Egy motor és egy ventilátor egy Modbus RTU I/O modulon, a HDMI képernyőről, a WEBview-ból és Home Assistantból vezérelve, egy Modbus TCP mérővel, CAN keretekkel, üzemórákkal, egy trenddel, a riasztásokkal és minden változóval az OPC UA-n. |
