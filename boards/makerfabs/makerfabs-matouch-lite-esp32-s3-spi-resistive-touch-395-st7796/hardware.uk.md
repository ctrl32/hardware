# Обладнання та підключення

## Що вам потрібно

- Makerfabs MaTouch Lite ESP32-S3 3,95" (ST7796).
- USB-C кабель для даних - для завантаження та живлення.
- Назва та пароль вашої мережі Wi-Fi 2,4 ГГц.
- ПК з [редактором ctrl32](https://ctrl32.com/download/) (Windows).
- Необов'язково, для прикладу all-in-one: релейний модуль або світлодіод на GPIO4, потенціометр (10 к) між 3,3 В і GND з повзунком на GPIO5 (роз'єми JST) і CAN-трансивер 3,3 В (напр. SN65HVD230) на GPIO6 / GPIO7.

## Живлення

| Джерело | Де | Примітка |
|---|---|---|
| USB 5 В | роз'єм USB-C | живлення та програмування |
| Li-Po акумулятор | роз'єм акумулятора | 3,7 В |

## Карта пінів

![Makerfabs MaTouch Lite ESP32-S3 3.95" - карта пінів](pinout/pinout.png)

| GPIO | Функція в ctrl32 | Примітка |
|---|---|---|
| 0 | BOOT BTN | ⚠ strapping-пін |
| 1 | TFT RST |  |
| 2 | SD CMD | ⚠  |
| 4 | вільний - ввід/вивід | ADC1 |
| 5 | вільний - ввід/вивід | ADC1 |
| 6 | вільний - ввід/вивід | ADC1 |
| 7 | вільний - ввід/вивід | ADC1 |
| 13 | TFT MOSI |  |
| 14 | TFT SCLK |  |
| 15 | TFT CS |  |
| 21 | TFT DC |  |
| 38 | TOUCH SDA |  |
| 39 | TOUCH SCL |  |
| 40 | TOUCH INT |  |
| 41 | SD DO | ⚠  |
| 42 | SD SCLK | ⚠  |
| 48 | TFT BL |  |

Два роз'єми **JST** виводять чотири вільні піни (від GPIO4 до GPIO7) -
їх мало, тому приклад виводить на них вихід, аналоговий вхід і CAN; більше
входів/виходів підключається через Modbus TCP або мікросхеми I2C. Дисплей,
контролер сенсора та слот microSD займають решту пінів.

## Безпека

- Плата не призначена для функцій безпеки. Аварійна зупинка, дверний
  вимикач або світлова завіса підключаються апаратно, ніколи через
  програму чи сенсорний екран.
- Піни GPIO працюють на 3,3 В. Котушка реле потребує драйвера (релейний модуль його має).
