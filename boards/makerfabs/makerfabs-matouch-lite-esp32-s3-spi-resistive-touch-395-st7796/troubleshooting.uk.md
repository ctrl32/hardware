# Усунення несправностей

| Симптом | Причина | Рішення |
|---|---|---|
| COM-порт не з'являється, вибір порту залишається порожнім | Кабель передає лише живлення або бракує драйвера USB | Використайте кабель для даних; встановіть драйвер USB-чипа плати; спробуйте інший USB-порт. |
| Flash runtime зупиняється під час підключення | Порт зайнято іншою програмою | Закрийте монітор послідовного порту або інший інструмент, який тримає порт відкритим, і спробуйте знову. |
| Плата перезапускається кожні кілька секунд | USB-порт не дає достатнього струму | Використайте USB-хаб із власним живленням або блок живлення 5 В щонайменше на 1 А. |
| Плата не підключається до Wi-Fi | Неправильна назва мережі чи пароль або мережа лише 5 ГГц | Перевірте назву та пароль на сторінці WiFi; ESP32 підключається лише до мереж 2,4 ГГц. |
| Плату не знайдено за її іменем .local | Мережа блокує mDNS (multicast) | Використайте IP-адресу плати - її показують список клієнтів маршрутизатора та Find devices у редакторі. |
| Вихід нічого не робить | Пін лише вхідний, або вказано не той пін | Перевірте пін на сторінці плати - піни лише для входу позначено; перенесіть вихід на вільний пін вводу/виводу. |
| Значення Modbus залишається 0 | Неправильна адреса пристрою, unit чи регістр | Перевірте IP і unit пристрою в дереві пристроїв, а регістр - у посібнику пристрою. |
| CAN мовчить | Немає термінування 120 Ом або інша швидкість передачі | Встановіть резистор 120 Ом на обох кінцях шини; задайте однакову швидкість передачі на кожному вузлі. |
| Значення Modbus RTU залишається 0 | A і B переплутано або неправильні unit, швидкість чи парність | Поміняйте A і B; перевірте unit, швидкість і парність пристрою. |

Панель **Messages** редактора та **діагностичний буфер** плати (Online → Diagnostics) кажуть, що вирішив runtime і чому - прочитайте їх насамперед.
