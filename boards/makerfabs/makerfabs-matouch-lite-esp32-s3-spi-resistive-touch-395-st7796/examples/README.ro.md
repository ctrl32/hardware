# Proiecte exemplu

Fiecare proiect se deschide în editorul ctrl32 (**File → Open**) și rulează pe Makerfabs MaTouch Lite ESP32-S3 3.95" așa cum este.

| | Proiect | Ce arată |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.ro.md) | O ieșire de motor cu start / stop, un temporizator de funcționare, un nivel analogic, cadre CAN, un contor Modbus TCP, MQTT și un ecran tactil. |
