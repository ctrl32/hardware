|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.de.md) | Ein Motorausgang mit Start / Stop, einer Laufzeit, einem analogen Füllstand, CAN-Frames, einem Modbus-TCP-Zähler, MQTT und einem Touchscreen. |
