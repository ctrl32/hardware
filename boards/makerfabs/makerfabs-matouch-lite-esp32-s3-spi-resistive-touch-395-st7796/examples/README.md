# Example projects

Each project opens in the ctrl32 editor (**File → Open**) and runs on the Makerfabs MaTouch Lite ESP32-S3 3.95" as it is.

| | Project | What it shows |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.md) | A motor output with start / stop, a run timer, an analog level, CAN frames, a Modbus TCP meter, MQTT and a touch screen. |
