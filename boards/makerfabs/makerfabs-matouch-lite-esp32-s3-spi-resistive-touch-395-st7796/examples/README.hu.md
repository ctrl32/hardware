# Példaprojektek

Minden projekt megnyílik a ctrl32 szerkesztőben (**File → Open**), és változtatás nélkül fut a(z) Makerfabs MaTouch Lite ESP32-S3 3.95" panelen.

| | Projekt | Mit mutat |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.hu.md) | Egy motorkimenet start / stop vezérléssel, futásidővel, analóg szinttel, CAN keretekkel, Modbus TCP mérővel, MQTT-vel és érintőképernyővel. |
