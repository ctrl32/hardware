# Progetti di esempio

Ogni progetto si apre nell'editor ctrl32 (**File → Open**) e funziona così com'è sulla Makerfabs MaTouch Lite ESP32-S3 3.95".

| | Progetto | Cosa mostra |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.it.md) | Un'uscita motore con start / stop, un timer di funzionamento, un livello analogico, frame CAN, un contatore Modbus TCP, MQTT e uno schermo touch. |
