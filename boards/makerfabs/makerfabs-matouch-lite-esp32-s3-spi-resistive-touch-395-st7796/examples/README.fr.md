# Projets d'exemple

Chaque projet s'ouvre dans l'éditeur ctrl32 (**File → Open**) et fonctionne tel quel sur la Makerfabs MaTouch Lite ESP32-S3 3.95".

| | Projet | Ce qu'il montre |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.fr.md) | Une sortie moteur avec marche / arrêt, une minuterie de marche, un niveau analogique, des trames CAN, un compteur Modbus TCP, MQTT et un écran tactile. |
