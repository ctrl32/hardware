# Example projects

Each project opens in the ctrl32 editor (**File → Open**) and runs on the Makerfabs MaTouch ESP32-P4 7" as it is.

| | Project | What it shows |
|---|---|---|
| ![All-in-one](all-in-one/img/screen.png) | [All-in-one](all-in-one/README.md) | A motor controlled from the touch screen, two buttons and Home Assistant, with a pressure gauge, a fan on a Modbus RTU temperature, a Modbus TCP power meter, CAN frames, a trend and the alarms. |
